# Training Metric Contract v1 - 训练指标契约 v1

**版本**: v1.0  
**日期**: 2026-04-18  
**阶段**: Phase 14 - Controlled Training, Behavior Internalization & Governance-Aligned Learning

---

## 1. 概述

本文档定义 Phase 14 训练的完整指标体系，确保训练目标与产品行为一致，不只是优化 loss。

### 1.1 核心原则

1. **多目标优化** - 不只是语言建模 loss
2. **行为优先** - 关注策略选择、检索触发、治理动作
3. **可解释性** - 每个指标都有明确的业务含义
4. **分层评估** - 训练期指标 vs 产品期指标

---

## 2. 指标体系架构

```
总损失函数
├── L_resp: 最终回答质量 (20%)
├── L_policy: 五类响应策略分类 (25%)
├── L_retrieval: 检索触发判断 (20%)
├── L_confidence: 置信度校准 (10%)
├── L_governance: 治理动作匹配 (15%)
├── L_memory: 写回正确性 (5%)
└── L_consistency: 多轮一致性 (5%)
```

---

## 3. 详细指标定义

### 3.1 L_resp: 最终回答质量

**目标**: 训练回答的流畅度、准确性、有用性

**组成**:

| 子指标 | 权重 | 说明 |
|--------|------|------|
| L_lm | 60% | 标准语言建模损失 |
| L_quality | 30% | 质量评分损失 |
| L_style | 10% | 风格一致性损失 |

**计算公式**:
```
L_resp = 0.6 * L_lm + 0.3 * L_quality + 0.1 * L_style
```

**评估方式**:
- 自动: Perplexity, BLEU, ROUGE
- 人工: 流畅度、准确性、有用性评分

---

### 3.2 L_policy: 五类响应策略分类

**目标**: 训练正确的响应策略选择

**类别**:
- DIRECT (直接回答)
- RETRIEVAL_FIRST (检索优先)
- CONSERVATIVE (保守回答)
- DECLINE (拒绝回答)
- REVIEW (需要审查)

**损失函数**:
```python
L_policy = CrossEntropy(predicted_strategy, ground_truth_strategy)
```

**评估指标**:

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 策略准确率 | > 85% | 选择正确策略的比例 |
| DIRECT 精确率 | > 90% | 直接回答的精确率 |
| DECLINE 召回率 | > 80% | 拒绝回答的召回率 |
| 混淆矩阵 | - | 各类别间的混淆情况 |

**验收标准**:

| 等级 | 策略准确率 | 状态 |
|------|------------|------|
| 优秀 | > 90% | 通过 |
| 良好 | 85-90% | 可接受 |
| 待改进 | < 85% | 需优化 |

---

### 3.3 L_retrieval: 检索触发判断

**目标**: 训练正确的检索触发时机

**损失函数**:
```python
L_retrieval = BCEWithLogitsLoss(
    predicted_retrieval_prob, 
    should_retrieve_ground_truth
)
```

**评估指标**:

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 检索触发准确率 | > 80% | 正确判断是否需要检索 |
| 精确率 | > 75% | 触发检索的精确率 |
| 召回率 | > 85% | 需要检索时的召回率 |
| F1 Score | > 80% | 综合指标 |

**关键指标**:

| 场景 | 目标 | 说明 |
|------|------|------|
| 应检未检率 | < 10% | 需要检索但没触发 |
| 过度检索率 | < 15% | 不需要但触发了 |

---

### 3.4 L_confidence: 置信度校准

**目标**: 训练准确的置信度估计

**损失函数**:
```python
# 期望校准误差
L_confidence = ECE(predicted_confidence, accuracy)
```

**评估指标**:

| 指标 | 目标值 | 说明 |
|------|--------|------|
| ECE | < 0.05 | 期望校准误差 |
| 高置信准确率 | > 95% | 置信度>0.9时的准确率 |
| 低置信识别 | > 70% | 置信度<0.6时的错误识别率 |

**校准曲线**:
```
置信度区间 | 期望准确率 | 实际准确率 | 偏差
-----------|------------|------------|------
0.9-1.0   | 95%+      | ?          | < 5%
0.8-0.9   | 85-95%    | ?          | < 10%
0.6-0.8   | 60-85%    | ?          | < 15%
< 0.6     | < 60%     | ?          | 触发DECLINE
```

---

### 3.5 L_governance: 治理动作匹配

**目标**: 训练正确的治理动作选择

**治理动作**:
- TSLA (初判)
- STRONG_REVIEW (强审查)
- VALIDATION (验证)
- ISOLATE (隔离)
- ARCHIVE (归档)
- PROMOTE (晋升)

**损失函数**:
```python
L_governance = CrossEntropy(predicted_actions, ground_truth_actions)
```

**评估指标**:

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 治理动作准确率 | > 85% | 选择正确治理动作 |
| TSLA 触发率 | - | 初判覆盖率 |
| 强审查准确率 | > 90% | 高风险识别 |
| 误晋升率 | < 1% | 错误晋升比例 |

---

### 3.6 L_memory: 写回正确性

**目标**: 训练正确的记忆写回决策

**损失函数**:
```python
L_memory = BCEWithLogitsLoss(
    predicted_writeback,
    should_writeback_ground_truth
) + CrossEntropy(
    predicted_layer,
    target_layer_ground_truth
)
```

**评估指标**:

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 写回决策准确率 | > 85% | 正确判断是否写回 |
| 层级选择准确率 | > 90% | 选择正确目标层 |
| 误写回率 | < 5% | 不该写回却写了 |
| 漏写回率 | < 10% | 该写回却没写 |

---

### 3.7 L_consistency: 多轮一致性

**目标**: 训练多轮对话中的人格一致性

**损失函数**:
```python
L_consistency = MSE(
    current_response_embedding,
    expected_persona_embedding
)
```

**评估指标**:

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 人格一致性 | > 90% | 多轮风格一致 |
| 双语一致性 | > 85% | 中英文行为一致 |
| 上下文引用准确率 | > 80% | 正确引用历史 |

## 6. 监控与告警

### 6.1 训练监控

| 指标 | 告警阈值 | 动作 |
|------|----------|------|
| Loss 突增 | > 2x 平均 | 检查数据 |
| 策略准确率下降 | < 基线 | 停止训练 |
| 置信度漂移 | ECE > 0.1 | 调整校准 |
| 治理误晋升 | > 5% | 紧急停止 |

### 6.2 评估监控

| 指标 | 检查频率 | 报告方式 |
|------|----------|----------|
| 验证集指标 | 每 epoch | 自动报告 |
| 产品行为指标 | 每 stage | 人工审核 |
| 基线对比 | 每 stage | 对比报告 |
