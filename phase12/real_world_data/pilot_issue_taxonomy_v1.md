# Pilot Issue Taxonomy v1 - 试运行问题分类 v1

**版本**: v1.0  
**日期**: 2026-04-18  
**阶段**: Phase 12 - WP2: 真实场景数据收集与分析

---

## 1. 概述

本文档定义 Phase 12 Pilot 试运行期间问题的分类体系，用于系统化地识别、记录和解决问题。

### 1.1 目标

- 建立统一的问题分类标准
- 支持问题统计和趋势分析
- 指导问题优先级和分配

---

## 2. 问题分类体系

### 2.1 一级分类

```
问题 (Issue)
├── 检索问题 (Retrieval)
├── 治理问题 (Governance)
├── 英文检测问题 (English Detection)
├── Memory 问题 (Memory)
├── 服务稳定性 (Stability)
├── 产品接口 (Product Interface)
└── 用户理解 (User Understanding)
```

### 2.2 检索问题 (Retrieval Issues)

| 二级分类 | 三级分类 | 描述 | 示例 |
|----------|----------|------|------|
| 检索失败 | 服务不可用 | 检索服务无法访问 | 连接超时 |
| | 索引损坏 | 索引数据异常 | 返回错误结果 |
| | 查询解析失败 | 无法理解查询 | 复杂查询报错 |
| 结果不相关 | 语义不匹配 | 结果与意图不符 | 搜索"苹果"返回水果 |
| | 上下文丢失 | 未考虑对话历史 | 多轮对话断裂 |
| | 排序错误 | 相关度排序问题 | 重要结果在后 |
| 召回不足 | 漏检相关记忆 | 未找到相关记忆 | 已知信息未返回 |
| | 过滤过度 | 过滤器过于严格 | 有效结果被过滤 |
| 性能问题 | 检索延迟高 | 响应时间过长 | P95 > 500ms |
| | 缓存失效 | 缓存策略问题 | 命中率过低 |

### 2.3 治理问题 (Governance Issues)

| 二级分类 | 三级分类 | 描述 | 示例 |
|----------|----------|------|------|
| TSLA 计算偏差 | 置信度计算错误 | 置信度评分异常 | 高错误内容得高分 |
| | 稳定性评估偏差 | 稳定性评分不准 | 波动内容得高分 |
| | 污染检测失效 | 未识别污染 | 错误信息进入永久层 |
| 动作决策错误 | 错误晋升 | 应隔离却晋升 | 错误内容晋升 |
| | 错误降级 | 应保留却降级 | 优质内容降级 |
| | 误隔离 | 正常内容被隔离 | 误判为污染 |
| 门限判断失误 | 晋升门限过高 | 优质内容无法晋升 | 晋升率过低 |
| | 隔离门限过低 | 过多内容被隔离 | 隔离率过高 |
| | 回流门限不当 | 回流机制失效 | 应回流未回流 |

### 2.4 英文检测问题 (English Detection Issues)

| 二级分类 | 三级分类 | 描述 | 示例 |
|----------|----------|------|------|
| 关系漏检 | SVO 漏检 | 未识别主谓宾关系 | "The cat sits on the mat" |
| | 介词关系漏检 | 未识别介词关系 | "in", "on", "at" |
| | 从属关系漏检 | 未识别从属关系 | "of", "'s" |
| 误召回 | 错误识别关系 | 不存在的关系 | 将形容词误判为关系 |
| | 边界错误 | 实体边界识别错误 | "New York" 被拆分 |
| | 多关系冲突 | 同一文本多关系 | 冲突的关系识别 |
| 精度问题 | 置信度不准 | 置信度与实际不符 | 高置信度但错误 |
| | 类型判断错误 | 关系类型错误 | 因果关系误判为条件 |

### 2.5 Memory 问题 (Memory Issues)

| 二级分类 | 三级分类 | 描述 | 示例 |
|----------|----------|------|------|
| 写回失败 | 事务超时 | 事务执行超时 | 30s 超时 |
| | 锁冲突 | 并发写入冲突 | 死锁或等待 |
| | 存储异常 | 底层存储错误 | 磁盘满、权限 |
| 事务回滚 | 原子性失败 | 部分操作失败 | 原子事务回滚 |
| | 依赖缺失 | 依赖对象不存在 | 引用的记忆缺失 |
| | 验证失败 | 数据验证不通过 | 格式、范围检查 |
| 数据不一致 | 层级不一致 | 记忆层级错误 | 应在长期却在短期 |
| | 状态不一致 | 记忆状态异常 | 已删除仍可访问 |
| | 索引不一致 | 索引与实际不符 | 检索到已删除 |
| 生命周期问题 | 过期未清理 | 超期记忆未处理 | 占用存储 |
| | 错误保留 | 应删除却保留 | 污染内容保留 |

### 2.6 服务稳定性 (Stability Issues)

| 二级分类 | 三级分类 | 描述 | 示例 |
|----------|----------|------|------|
| 超时 | 检索超时 | 检索响应超时 | > 1s |
| | 治理超时 | 治理决策超时 | > 2s |
| | 写回超时 | 记忆写回超时 | > 3s |
| | 端到端超时 | 整体响应超时 | > 5s |
| 错误 | 服务崩溃 | 进程异常退出 | OOM、panic |
| | 依赖故障 | 依赖服务故障 | DB、缓存故障 |
| | 资源耗尽 | CPU/内存/连接耗尽 | 负载过高 |
| 降级触发 | 检索降级 | 检索服务异常降级 | 缓存模式 |
| | 治理降级 | 治理服务异常降级 | 简化决策 |
| | 写回降级 | 写回服务异常降级 | 只读模式 |

### 2.7 产品接口 (Product Interface Issues)

| 二级分类 | 三级分类 | 描述 | 示例 |
|----------|----------|------|------|
| 响应格式 | 格式错误 | JSON/XML 格式异常 | 解析失败 |
| | 字段缺失 | 必需字段缺失 | 缺少 confidence |
| | 类型错误 | 数据类型不匹配 | 字符串 vs 数字 |
| 错误提示 | 提示不清 | 错误信息不明确 | "系统错误" |
| | 无错误码 | 缺少错误码 | 无法程序化判断 |
| | 多语言缺失 | 错误信息未翻译 | 仅英文 |
| 交互体验 | 响应过慢 | 用户感知延迟 | 白屏时间过长 |
| | 状态不同步 | 前后端状态不一致 | 显示与后台不符 |
| | 边界处理 | 极端情况处理 | 空输入、超长输入 |

### 2.8 用户理解 (User Understanding Issues)

| 二级分类 | 三级分类 | 描述 | 示例 |
|----------|----------|------|------|
| 期望偏差 | 结果不符预期 | 输出与用户期望不同 | 用户想要 A 得到 B |
| | 能力误解 | 用户误解系统能力 | 期望系统做不到的事 |
| | 范围误解 | 用户误解适用范围 | 超出支持的语言/场景 |
| 使用困惑 | 不知如何提问 | 用户不会构造查询 | 输入无效问题 |
| | 不理解输出 | 用户不理解系统回答 | 专业术语过多 |
| | 多轮迷失 | 多轮对话中迷失 | 忘记上下文 |
| 反馈问题 | 无法反馈 | 反馈渠道不畅 | 找不到反馈入口 |
| | 反馈无响应 | 反馈后无处理 | 石沉大海 |
| | 反馈无效 | 反馈未被采纳 | 重复出现 |

## 3. 问题严重度

### 3.1 严重度定义

| 级别 | 名称 | 定义 | 响应时间 | 示例 |
|------|------|------|----------|------|
| P0 | 致命 | 系统不可用或核心功能完全失效 | 立即 | 服务崩溃、数据丢失 |
| P1 | 严重 | 核心功能受损或重要功能不可用 | 2 小时 | 检索失败、治理错误 |
| P2 | 一般 | 功能降级或非核心功能问题 | 24 小时 | 性能下降、格式错误 |
| P3 | 轻微 | 体验问题或优化建议 | 72 小时 | 提示不清、界面问题 |

### 3.2 严重度判定矩阵

| 因素 | P0 | P1 | P2 | P3 |
|------|-----|-----|-----|-----|
| 影响范围 | 全部用户 | 大量用户 | 部分用户 | 个别用户 |
| 功能影响 | 完全不可用 | 主要功能受损 | 功能降级 | 体验影响 |
| 数据风险 | 数据丢失 | 数据错误 | 无 | 无 |
| 恢复难度 | 需紧急修复 | 需快速修复 | 计划修复 | 排期修复 |

## 4. 问题状态

| 状态 | 说明 | 转移条件 |
|------|------|----------|
| 新建 | 刚发现问题 | 分配给处理人 |
| 已确认 | 确认问题存在 | 开始修复 |
| 处理中 | 正在修复 | 修复完成 |
| 待验证 | 修复完成待验证 | 验证通过 |
| 已解决 | 验证通过 | - |
| 已关闭 | 问题解决 | - |
| 已拒绝 | 非问题或重复 | - |
| 已挂起 | 暂时无法处理 | 条件允许后继续 |
