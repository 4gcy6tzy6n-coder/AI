**版本**: v1.0

**阶段**: Phase 12 - WP1: Pilot 试运行执行

---

## 1. 概述

本文档定义 Phase 12 Pilot 试运行的执行计划，包括范围定义、模式设计、运行策略和报告机制。

### 1.1 目标

把系统放到受控真实环境中，验证其在真实任务与真实交互下的表现。

### 1.2 原则

- 小流量、可观测、可回滚
- 真实数据优先于主观判断
- 风险边界必须明确
- 线上问题必须闭环

## 2. Pilot 范围定义

### 2.1 用户范围

| 类别 | 范围 | 说明 |
|------|------|------|
| 内部用户 | ✅ 包含 | 开发团队、测试团队 |
| 试用组 | ✅ 包含 | 熟悉系统的早期用户 |

| 中风险 | ✅ | 复杂查询、多步推理 |
| 高风险 | ❌ | 关键业务、不可回滚任务 |

### 2.3 语言范围

| 语言 | 占比 | 说明 |
|------|------|------|
| 中文 | 70% | 主语言 |

### 2.4 流量范围

| 指标 | 数值 | 说明 |
|------|------|------|
| 日最大请求量 | 10,000 | 软限制 |

| 并发连接数 | 50 | 最大并发 |

### 2.5 时间范围

| 阶段 | 时长 | 目标 |
|------|------|------|
| Shadow 阶段 | 1 周 | 验证链路，不返回结果 |

**总计**: 7 周

## 3. Pilot 模式设计

### 3.1 Shadow 模式

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   用户请求   │────▶│  生产系统   │────▶│  返回结果   │
└─────────────┘     └─────────────┘     └─────────────┘
                            │
                            ▼
                     ┌─────────────┐
                     │  Pilot 系统  │
                     │  (仅记录)   │
                     └─────────────┘
```

- Pilot 系统接收相同请求
- 不返回结果给用户
- 仅记录日志和指标
- 用于验证链路稳定性

### 3.2 Canary 模式

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   用户请求   │────▶│  流量分配器  │────▶│  生产系统   │
└─────────────┘     └─────────────┘     └─────────────┘
                            │
                            ▼ (5% 流量)
                     ┌─────────────┐
                     │  Pilot 系统  │
                     │ (返回结果)  │
                     └─────────────┘
```

- 5% 流量进入 Pilot 系统
- 返回结果给用户
- 全链路监控
- 人工复核

### 3.3 人工复核模式

| 触发条件 | 复核比例 | 说明 |
|----------|----------|------|
| 英文任务 | 100% | 所有英文输出需复核 |
| 置信度 < 0.7 | 100% | 低置信度结果需复核 |
| 治理动作 = quarantine | 100% | 隔离对象需复核 |
| 其他 | 10% | 抽样复核 |

### 3.4 限流模式

| 限流维度 | 阈值 | 动作 |
|----------|------|------|
| 全局 QPS | 100 | 拒绝新请求 |
| 单用户 QPS | 1 | 延迟响应 |
| 错误率 > 5% | - | 自动降级 |
| 延迟 P95 > 1s | - | 触发告警 |

### 3.5 强监控模式

- 全链路日志采集
- 实时指标仪表盘
- 异常自动告警
- 1 分钟级监控粒度

## 4. Pilot 运行策略

### 4.1 错误阈值触发降级

| 指标 | 阈值 | 降级动作 |
|------|------|----------|
| 错误率 | > 5% | 流量回切至生产系统 |
| 超时率 | > 10% | 降低并发限制 |
| 检索失败率 | > 15% | 关闭检索增强 |

### 4.2 检索服务异常降级

```python
# 降级策略
if retrieval_service_error_rate > 0.15:
    # 降级为仅使用缓存
    use_cache_only = True
    
if retrieval_service_timeout_rate > 0.20:
    # 降级为不使用检索
    disable_retrieval = True
    
if memory_service_error_rate > 0.10:
    # 降级为只读模式
    memory_writeback_enabled = False
```

### 4.3 Memory 写回策略

| 阶段 | 写回策略 | 说明 |
|------|----------|------|
| Shadow | 只读 | 不写回 |
| Canary Week 1 | 仅晋升 | 只执行 promote 动作 |
| Canary Week 2 | 全动作 | 开放所有治理动作 |
| 扩大阶段 | 全动作 | 正常写回 |
