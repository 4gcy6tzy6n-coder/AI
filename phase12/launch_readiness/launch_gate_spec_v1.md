# Launch Gate Spec v1 - 上线门禁规格 v1

**版本**: v1.0  
**日期**: 2026-04-18  
**阶段**: Phase 12 - WP3: 上线门禁与全面上线准备

---

## 1. 概述

本文档定义系统全面上线的门禁标准，把"能试运行"推进为"是否可正式上线"的可判定状态。

### 1.1 目标

建立清晰、可执行的上线门禁，确保只有满足条件的系统才能进入全面上线阶段。

### 1.2 原则

- 门禁必须量化、可验证
- 不满足门禁不强行上线
- 门禁可根据 Pilot 数据调整

---

## 2. 上线门禁定义

### 2.1 查询成功率门禁

| 指标 | 阈值 | 说明 | 验证方式 |
|------|------|------|----------|
| 查询成功率 | ≥ 99.5% | 端到端成功率 | Pilot 数据 |
| 错误率 | < 0.5% | 系统错误占比 | 日志统计 |
| 超时率 | < 1% | 超时请求占比 | 监控数据 |

**门禁逻辑**: 连续 7 天满足阈值

### 2.2 检索成功率门禁

| 指标 | 阈值 | 说明 | 验证方式 |
|------|------|------|----------|
| 检索成功率 | ≥ 99% | 检索服务可用性 | 服务监控 |
| 缓存命中率 | ≥ 30% | 缓存效率 | 性能指标 |
| 检索延迟 P95 | < 200ms | 检索响应时间 | APM 数据 |

### 2.3 治理链完成率门禁

| 指标 | 阈值 | 说明 | 验证方式 |
|------|------|------|----------|
| 治理完成率 | ≥ 98% | 治理决策成功率 | 治理日志 |
| TSLA 计算成功率 | ≥ 99% | 评分计算成功率 | 治理日志 |
| 决策延迟 P95 | < 100ms | 治理响应时间 | APM 数据 |

### 2.4 永久层污染率门禁

| 指标 | 阈值 | 说明 | 验证方式 |
|------|------|------|----------|
| 污染率 | < 2% | 错误进入永久层比例 | 抽样检查 |
| 隔离率 | < 5% | 进入隔离区比例 | 治理统计 |
| 回流修复率 | ≥ 80% | 回流后修复成功比例 | 回流日志 |

### 2.5 写回异常率门禁

| 指标 | 阈值 | 说明 | 验证方式 |
|------|------|------|----------|
| 写回成功率 | ≥ 99% | 事务提交成功率 | 写回日志 |
| 事务回滚率 | < 1% | 事务回滚比例 | 事务日志 |
| 死锁率 | < 0.1% | 死锁发生比例 | 错误日志 |

### 2.6 延迟门禁

| 指标 | Pilot 目标 | 全量目标 | 验证方式 |
|------|------------|----------|----------|
| P50 延迟 | < 200ms | < 300ms | APM |
| P95 延迟 | < 500ms | < 800ms | APM |
| P99 延迟 | < 1000ms | < 1500ms | APM |

### 2.7 告警响应时间门禁

| 指标 | 阈值 | 说明 | 验证方式 |
|------|------|------|----------|
| P0 响应时间 | < 5 分钟 | 关键故障 | 告警系统 |
| P1 响应时间 | < 30 分钟 | 重要故障 | 告警系统 |
| P2 响应时间 | < 2 小时 | 一般问题 | 告警系统 |

### 2.8 英文关系检测门禁

| 指标 | 阈值 | 说明 | 验证方式 |
|------|------|------|----------|
| 英文 F1 | ≥ 0.65 | 关系检测 F1 分数 | 测试集 |
| 英文精确率 | ≥ 0.70 | 精确率 | 测试集 |
| 英文召回率 | ≥ 0.60 | 召回率 | 测试集 |

**说明**: 英文能力作为灰度限制条件，不阻塞整体上线

### 2.9 用户满意度门禁

| 指标 | 阈值 | 说明 | 验证方式 |
|------|------|------|----------|
| 人工复核通过率 | ≥ 90% | 复核结果通过率 | 复核记录 |
| 用户满意度 | ≥ 4.0/5 | 用户评分 | 反馈系统 |
| 负面反馈率 | < 5% | 负面反馈占比 | 反馈统计 |

## 3. 门禁汇总表

| 门禁项 | 阈值 | 权重 | 是否阻塞 |
|--------|------|------|----------|
| 查询成功率 | ≥ 99.5% | 高 | ✅ 是 |
| 检索成功率 | ≥ 99% | 高 | ✅ 是 |
| 治理链完成率 | ≥ 98% | 高 | ✅ 是 |
| 永久层污染率 | < 2% | 高 | ✅ 是 |
| 写回异常率 | < 1% | 高 | ✅ 是 |
| P95 延迟 | < 500ms | 中 | ✅ 是 |
| 告警响应 P0 | < 5min | 中 | ⚠️ 建议 |
| 英文 F1 | ≥ 0.65 | 低 | ❌ 否 |
| 用户满意度 | ≥ 4.0 | 中 | ⚠️ 建议 |

**阻塞项**: 必须全部满足才能上线  
**建议项**: 不满足可评估后决定  
**非阻塞项**: 仅作为灰度限制

## 4. 门禁验证流程

### 4.1 验证周期

| 阶段 | 时长 | 目标 |
|------|------|------|
| 数据收集 | 7 天 | 收集连续 7 天数据 |
| 数据分析 | 2 天 | 统计各项指标 |
| 门禁评估 | 1 天 | 判断是否满足 |
| 决策会议 | 1 天 | 上线决策 |

### 4.2 验证检查清单

```markdown
## 上线门禁验证检查清单

### 查询成功率
- [ ] 连续 7 天成功率 ≥ 99.5%
- [ ] 错误率 < 0.5%
- [ ] 超时率 < 1%

### 检索成功率
- [ ] 检索成功率 ≥ 99%
- [ ] 缓存命中率 ≥ 30%
- [ ] P95 延迟 < 200ms

### 治理链完成率
- [ ] 治理完成率 ≥ 98%
- [ ] TSLA 成功率 ≥ 99%
- [ ] P95 延迟 < 100ms

### 永久层污染率
- [ ] 污染率 < 2%
- [ ] 隔离率 < 5%
- [ ] 回流修复率 ≥ 80%

### 写回异常率
- [ ] 写回成功率 ≥ 99%
- [ ] 回滚率 < 1%
- [ ] 死锁率 < 0.1%

### 延迟
- [ ] P50 < 200ms
- [ ] P95 < 500ms
- [ ] P99 < 1000ms

### 告警响应
- [ ] P0 < 5min
- [ ] P1 < 30min

### 英文能力
- [ ] F1 ≥ 0.65 (非阻塞)

### 用户满意度
- [ ] 复核通过率 ≥ 90%
- [ ] 满意度 ≥ 4.0
```

## 5. 门禁豁免机制

### 5.1 豁免条件

| 条件 | 说明 | 审批 |
|------|------|------|
| 非阻塞项不满足 | 英文 F1 等 | 技术负责人 |
| 建议项不满足 | 告警响应等 | 项目负责人 |
| 阻塞项接近阈值 | 差距 < 0.5% | 需评估风险 |

### 5.2 豁免流程

```
1. 提出豁免申请
2. 说明原因和风险
3. 制定缓解措施
4. 技术负责人审批
5. 记录豁免决策
```

## 6. 阶段性门禁

### 6.1 Pilot 阶段门禁

| 指标 | 阈值 | 说明 |
|------|------|------|
| 稳定性 | 7 天无 P0 | 试运行稳定 |
| 可观测 | 全链路监控 | 数据完整 |
| 可回滚 | 回滚 < 5min | 风险控制 |

### 6.2 灰度阶段门禁

| 指标 | 阈值 | 说明 |
|------|------|------|
| 成功率 | ≥ 99% | 质量门槛 |
| 延迟 P95 | < 800ms | 性能门槛 |
| 用户反馈 | ≥ 3.5 | 体验门槛 |

### 6.3 全量上线门禁

| 指标 | 阈值 | 说明 |
|------|------|------|
| 成功率 | ≥ 99.5% | 生产质量 |
| 延迟 P95 | < 500ms | 生产性能 |
| 用户满意度 | ≥ 4.0 | 生产体验 |

## 7. 门禁调整机制

### 7.1 调整触发条件

| 条件 | 说明 |
|------|------|
| Pilot 数据异常 | 真实数据与预期差异大 |
| 业务需求变化 | 上线范围调整 |
| 技术能力变化 | 新能力引入或限制 |

### 7.2 调整流程

```
1. 收集调整理由
2. 评估影响范围
3. 提出新阈值
4. 评审确认
5. 更新文档
6. 通知相关方
```

---

## 8. 验收标准

| 标准 | 说明 | 验收方式 |
|------|------|----------|
| 门禁清晰 | 所有门禁量化可验证 | 文档评审 |
| 演练通过 | 发布与回滚演练通过 | 演练记录 |
| 问题处置 | Pilot 遗留问题有结果 | 问题清单 |
| 决策明确 | 可判断上线/暂缓 | 决策记录 |
