## 2. 发布流程

### 2.1 发布准备

- [ ] 创建 release/v{version} 分支
- [ ] 更新版本号
- [ ] 更新 CHANGELOG
- [ ] 执行完整回归测试
- [ ] 修复发现的问题
- [ ] 完成发布检查清单

### 2.2 发布候选 (RC)

- [ ] 标记 RC 版本 (v{version}-rc.1)
- [ ] 部署到 RC 环境
- [ ] 执行验收测试
- [ ] 性能基准测试
- [ ] 安全扫描
- [ ] 文档最终审核

### 2.3 正式发布

- [ ] 更新版本号到正式版本
- [ ] 合并 release 分支到 main
- [ ] 打标签 v{version}
- [ ] 创建 GitHub Release
- [ ] 部署到生产环境
- [ ] 验证生产部署
- [ ] 发送发布通知
