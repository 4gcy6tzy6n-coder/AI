Stage 9 的核心目标是解决 Stage 8 发现的多层任务跷跷板效应，实现 L1/L2/L3 任务的平衡训练与稳定共存。

### 1.1 主要目标

- 实现 L1/L2/L3 同时保持合理准确率

## 2. 实验历程与关键发现

### Stage 9-R1: 动态权重调整
- **策略**: 根据表现动态调整 L1/L2/L3 权重
- **结果**: 短暂平衡窗口 (20-30 steps)，随后完全切换到 L2/L3
- **发现**: 动态权重调整速度跟不上模型学习速度

### Stage 9-R2: 固定采样 + 严格平衡 ✅ **官方最优基线**
- **策略**: 
  - 固定采样比例: L1:L2:L3 = 2:2:1
  - 固定权重: L1=1.2, L2=1.2, L3=1.0
  - L1 replay: 每 10 步
  - Phase: 1-50 L1, 51-120 L1+L2, 121+ 全混合
- **结果**: 
  - **L1: 45%** | **L2: 77.5%** | **L3: 65%**
  - **Overall: 62.5%**
  - **Balance Window: 109 steps** (首次突破！)
  - **L1 从未清零**
- **结论**: **单模型多层任务共存首次验证成功！**

### Stage 9-R3: 微调收口 ⚠️ **边界验证**
- **策略**: 
  - L1 权重: 1.2 → 1.3
  - L1 replay: 每 10 步 → 每 8 步
  - 其他保持 R2 配置
- **结果**: 
  - L1: 42.5% | L2: 62.5% | L3: 65%
  - Balance Window: 仅 20 steps
  - 整体稳定性大幅下降
- **结论**: **R2 是当前参数区间的真实平衡点，继续强化 L1 会破坏整体平衡**

## 4. 官方最优基线配置 (R2)

### 4.1 训练配置
```python
# Stage 9 Official Balanced Baseline v1

# 采样策略
sampling_ratio = 'L1:L2:L3 = 2:2:1'
strict_balanced_batch = True  # 每 batch 强制包含所有层级

# 权重配置
fixed_weights = {
    'L1': 1.2,
    'L2': 1.2,
    'L3': 1.0,
}

# Replay 配置
replay_interval = 10  # 每 10 步
replay_weight = 0.5   # 降低权重，避免过度拉回

# 课程阶段
phase_steps = {
    'L1_warmup': (0, 50),
    'L1_L2': (50, 120),
    'L1_L2_L3': (120, 300),
}

# 优化器
learning_rate = 1e-4
grad_clip = 1.0
```

### 4.2 冻结配置 (Guard + TSLA)
```python
# Output KL Guard (冻结)
guard_beta = 0.2
guard_use_probs = True
guard_num_samples = 30

# TSLA 门控 (冻结)
promotion_threshold = 0.8
isolation_threshold = 0.3
```
