## 3. 深度分析

### 3.1 长期训练的价值

**关键发现：系统从早期震荡进入后期长期平衡**

```
早期 (0-300 steps): 跷跷板效应明显
  → L1 主导 → L1 清零 → L2/L3 主导

中期 (350+ steps): 系统自我调整
  → 进入稳定平衡区

后期 (600-999 steps): 长期稳定共存
  → 649 steps 持续平衡
```

**结论**: R2 基线不仅可持续，而且**长期表现优于短期**！

### 3.2 L1 短暂清零分析

| 维度 | 情况 |
|------|------|
| 发生时间 | Step 200-250 (仅 50 steps) |
| 持续时间 | 短暂，随后恢复 |
| 后续表现 | Step 300 后恢复至 30%，Step 350 后稳定 45-65% |
| 性质判断 | **暂时性震荡，非永久性失效** |

**与 R1 的区别**:
- R1: L1 永久清零，无法恢复
- S10-1: L1 短暂清零后**自动恢复并长期稳定**
