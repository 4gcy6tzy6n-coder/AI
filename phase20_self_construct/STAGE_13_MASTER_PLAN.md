## 3 条主线

### 1️⃣ H2 作为主攻方向

**数据支撑**: 100条失败案例中H2占48%

**目标**:
- 提升H2在陌生表达下的稳定性
- 覆盖更多H2变体、改写、口语表达、边界场景
- 重点验证真实分布下是否仍反复出现

**关键改进点**:
- 口语化H2表达识别 ("抢票脚本"、"自动抢的程序")
- 动作意图理解
- 边界判断逻辑

### 2️⃣ NORMAL 作为平衡约束

**数据支撑**: 100条失败案例中NORMAL占45%

**目标**:
- 正常查询不被误杀
- false positive 不反弹
- 已经稳定的H1/H4/H5不被冲坏

**关键约束**:
- 保持正常查询准确率 ≥ 90%
- 控制false positive rate
- 防止"修H2坏H1/H4/H5"

### 3️⃣ TSLA-v2 正式接入

**不仅是筛选，还要实现**:
- 错因归因
- 纠偏后复审
- 重复错误抑制
- 纠偏成功后的受控晋升

## TSLA-v2 核心功能

### 错因归因
```python
# 对每条错误进行归因分析
error_attribution = {
    'root_cause': 'h2_boundary_blur',  # h2边界模糊
    'context': '口语化表达',
    'similar_patterns': ['抢票脚本', '自动抢程序'],
    'correct_action': '回流重审'
}
```

### 纠偏后复审
```python
# 教师纠偏后，模型复审同类模式
review_trigger = {
    'condition': '同一模式错误 ≥ 3次',
    'action': '触发批量复审',
    'scope': '同类型变体'
}
```

### 重复错误抑制
```python
# 识别并抑制重复模式错误
suppression_rule = {
    'pattern': 'H2口语变体',
    'threshold': 2,  # 连续2次错误后抑制
    'action': '自动降级处理'
}
```

### 受控晋升
```python
# 纠偏成功后，受控晋升
promotion_rule = {
    'condition': '同类正确 ≥ 5次',
    'confidence_threshold': 0.9,
    'action': '晋升为长期层'
}
```
