# Stage 11-A: 教师退半场训练计划

## 阶段定位

**阶段名称**: Stage 11-A - 教师退半场训练 / Self-Learning Bootstrap Transition

**核心目标**: 把训练范式从"问题→教师答案→模型拟合"升级为"问题→自主思考→缺口识别→检索决策→检索整合→候选构建→TSLA决策→输出→记忆动作"

**本阶段不追求**: 完全脱离教师，一次性达到完全自主学习

**本阶段追求**:
1. 教师从"给完整答案"退到"给纠偏、评分、建议"
2. 模型开始真正使用架构链路
3. 让"主动学习闭环"第一次进入主训练流程

---

## 核心结论目标

训练结束后必须证明5件事:

1. ✅ 模型能判断自己是否缺信息
2. ✅ 模型能在缺信息时正确触发检索
3. ✅ 模型能把检索结果整合进回答
4. ✅ 模型能对自己的候选结果做初步治理判断
5. ✅ 模型对教师完整答案的依赖显著下降

---

## 教师角色转换

### 从"标准答案提供者"转为4种角色:

**角色A: 评分老师**
- 对模型回答给分，不直接替模型回答

**角色B: 纠错老师**
- 指出问题在哪，不直接给完整正确答案

**角色C: 检索建议老师**
- 告诉模型"这里需要查""应该查什么方向"

**角色D: 治理标注老师**
- 帮助标注: 是否应隔离/回流/晋升候选/不应写入

## 损失函数设计

### 多目标损失

```
L_total = α·L_answer + β·L_gap + γ·L_retrieval + δ·L_tsla + ε·L_memory + ζ·L_guard
```

### 推荐权重

| 损失项 | 权重 | 说明 |
|--------|------|------|
| L_answer | α=0.30 | 回答质量仍重要但非唯一 |
| L_gap | β=0.20 | 缺口识别进入主目标 |
| L_retrieval | γ=0.15 | 检索决策进入主目标 |
| L_tsla | δ=0.15 | TSLA动作进入主目标 |
| L_memory | ε=0.10 | 记忆动作进入主目标 |
| L_guard | ζ=0.10 | 保持稳定性 |

## 新增预测头

模型增加4个新输出头:

1. **缺口识别头** (gap_detection_head)
   - 输出: [无缺口, 有缺口]
   - 目标: 正确判断是否需要检索

2. **检索决策头** (retrieval_decision_head)
   - 输出: [不检索, 检索]
   - 目标: 正确触发检索

3. **策略选择头** (strategy_head)
   - 输出: [DIRECT, RETRIEVAL_FIRST, CONSERVATIVE, DECLINE, REVIEW]
   - 目标: 选择正确回答策略

4. **TSLA动作头** (tsla_action_head)
   - 输出: 8种治理动作
   - 目标: 预判正确治理动作

5. **记忆动作头** (memory_action_head)
   - 输出: 5种记忆动作
   - 目标: 正确决定记忆流向

## 三阶段训练流程

### Phase 11-A1: 教师半退场过渡 (1-2轮)

**目标**: 模型开始先做判断，再看教师纠偏

**教师参与比例**:
- 30% 完整答案参考
- 70% 纠偏/打分/建议

### Phase 11-A2: 链路主导训练 (2-4轮)

**目标**: 模型开始独立完成链路

**教师参与比例**:
- 10% 完整答案参考
- 90% 评分/纠偏/动作标注

### Phase 11-A3: 弱教师验收 (1轮)

**目标**: 验证即使教师不直接给答案，模型仍能完成主动学习链路

**教师参与比例**:
- 0-5% 完整答案
- 主要只给最终评分

---

## 验收指标

### 核心指标 (目标值)

| 指标 | 目标 | 说明 |
|------|------|------|
| Gap Detection Accuracy | 80% | 正确判断"是否缺信息" |
| Retrieval Trigger Accuracy | 75% | 该检索时检索，不该时不乱检索 |
| Retrieval Integration Score | 70% | 检索内容正确整合进回答 |
| TSLA Action Accuracy | 70% | 预判治理动作与标准一致 |
| Memory Action Accuracy | 70% | 正确判断记忆流向 |
| Teacher Dependence Ratio | <30% | 依赖教师直接答案的比例下降 |
| Writeback Stability | Δ<5% | 保持稳定性 |

## 关键转变总结

| 维度 | 之前 | Stage 11-A |
|------|------|------------|
| 教师角色 | 标准答案提供者 | 评分/纠偏/建议者 |
| 训练目标 | 拟合教师答案 | 学会完整学习链路 |
| 数据类型 | 问题-答案对 | 链路监督样本 |
| 评估指标 | Accuracy/Loss | 链路能力指标 |
| 核心能力 | 像老师回答 | 自己会学习 |

---

## 最关键的一句话

**下一阶段不该再训练"更像老师的模型"，而要训练"会自己决定是否该查、怎么查、如何整合、怎么治理、是否该写入"的模型。**

这才叫真正开始释放能力。
