## 2. 全链路追踪系统

### 2.1 追踪阶段

| 阶段 | 描述 | 记录内容 |
|------|------|----------|
| Input Snapshot | 输入快照 | 原始输入、解析结果 |
| Gap Identification | 缺口识别 | 识别结果、触发条件 |
| Retrieval | 检索 | 检索参数、结果、耗时 |
| TSLA | TSLA 决策 | 决策过程、动作 |
| Gateway | 门控分流 | 各门评分、分流结果 |
| Writeback | 写回 | 写回目标、结果 |
| Error Fix | 错误修复 | 修复记录 |

| 统计生成 | ✅ | 提供完整统计信息 |

|--------|--------|----------|
