### 2.2 扩展模式库

#### 新增模式类型

1. **主谓宾模式 (SVO)**
   - 基础模式: Subject Verb Object
   - 带助动词: Subject has/have/had Verb Object
   - 被动语态: Object was/were Verb by Subject

2. **介词关系模式**
   - 空间介词: on, in, at, under, above, below
   - 时间介词: before, after, during
   - 拥有介词: has, have, had, owns
   - 部分整体: part of, contains, includes

3. **因果关系模式**
   - A causes B
   - A is caused by B
   - If A, then B

4. **比较关系模式**
   - A is taller than B
   - A is as tall as B

5. **双宾语模式**
   - Subject gave Object1 Object2

## 3. 双语对齐评估

### 3.1 评估维度

1. **语义对齐**: 中英文是否表达相同语义
2. **治理动作对齐**: 是否触发相同的治理动作
3. **质量分数对齐**: 质量分数差异是否在阈值内 (0.1)
4. **Unit 类型一致性**: 识别的 Unit 类型是否一致

### 3.2 测试结果

| 指标 | 结果 | 目标 | 状态 |
|------|------|------|------|
| 语义对齐 | 1.00 | > 0.80 | ✅ 达标 |
| 治理动作对齐 | 1.00 | > 0.80 | ✅ 达标 |
| 质量分数差异 | 0.021 | < 0.10 | ✅ 达标 |
| Unit 类型一致性 | 0.44 | > 0.90 | ⚠️ 未达标 |
| 综合分数 | 0.85 | > 0.70 | ✅ 达标 |
| 通过率 | 100% | - | ✅ 通过 |

### 3.3 问题分析

**Unit 类型一致性偏低的原因**:
- 部分测试用例中英文 Unit 类型识别与期望不一致
- 关系类用例在英文中识别准确率有待提升
- 需要进一步优化英文 Unit 分类器
