# 实验审查清单

## 实验设计检查项

### 目标明确性
- [ ] 实验目标清晰
- [ ] 假设明确
- [ ] 成功标准定义

### 方法合理性
- [ ] 实验方法适当
- [ ] 控制变量考虑
- [ ] 样本量足够

### 可重复性
- [ ] 随机种子固定
- [ ] 环境配置记录
- [ ] 代码版本记录

## 数据质量检查项

### 数据集
- [ ] 数据集来源明确
- [ ] 数据预处理记录
- [ ] 数据分布分析
- [ ] 偏差检查

### 标注质量
- [ ] 标注指南完整
- [ ] 标注一致性检查
- [ ] 标注者间一致性

## 执行检查项

### 过程记录
- [ ] 执行时间记录
- [ ] 资源使用记录
- [ ] 异常事件记录

### 中间结果
- [ ] 检查点保存
- [ ] 日志完整
- [ ] 监控数据收集

## 分析检查项

### 统计分析
- [ ] 统计方法正确
- [ ] 显著性检验
- [ ] 效应量计算
- [ ] 置信区间提供

### 可视化
- [ ] 图表清晰
- [ ] 坐标轴标注
- [ ] 图例完整
- [ ] 颜色可区分

### 结论
- [ ] 结论基于数据
- [ ] 避免过度推断
- [ ] 局限性说明
- [ ] 未来工作建议

## 报告检查项

### 完整性
- [ ] 所有章节完整
- [ ] 原始数据可访问
- [ ] 代码可复现

### 清晰性
- [ ] 逻辑清晰
- [ ] 语言准确
- [ ] 术语一致

## 审查流程

1. **实验前审查**: 审查实验设计
2. **执行监控**: 监控实验执行
3. **结果审查**: 审查分析结果
4. **报告审查**: 审查实验报告
5. **最终确认**: 确认实验结论
