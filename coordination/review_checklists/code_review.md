# 代码审查清单

## 通用检查项

### 代码质量
- [ ] 代码遵循项目编码规范
- [ ] 使用类型注解
- [ ] 函数和类有文档字符串
- [ ] 复杂逻辑有注释
- [ ] 没有硬编码的魔法数字

### 测试
- [ ] 新功能有对应的单元测试
- [ ] 测试覆盖率 > 80%
- [ ] 边界条件有测试
- [ ] 错误处理有测试

### 性能
- [ ] 没有明显的性能问题
- [ ] 大数据集有考虑
- [ ] 避免不必要的循环

### 安全
- [ ] 没有敏感信息泄露
- [ ] 输入有验证
- [ ] 异常安全处理

## 模块特定检查项

### Unit 系统
- [ ] Unit 验证逻辑完整
- [ ] 序列化/反序列化正确
- [ ] 类型检查严格

### 思考引擎
- [ ] 推理步骤可追溯
- [ ] 状态管理正确
- [ ] 冲突检测有效

### 检索引擎
- [ ] 检索结果相关性高
- [ ] 缓存策略合理
- [ ] 错误处理完善

### 记忆系统
- [ ] 数据持久化正确
- [ ] 门控逻辑符合规范
- [ ] 迁移过程安全

### TSLA 系统
- [ ] 评分逻辑可解释
- [ ] 否决规则正确
- [ ] 审计日志完整

## 审查流程

1. **自测**: 开发者完成自查
2. **提交**: 提交 PR/变更
3. **审查**: 审查者逐项检查
4. **反馈**: 记录问题和建议
5. **修复**: 开发者修复问题
6. **确认**: 审查者确认通过
