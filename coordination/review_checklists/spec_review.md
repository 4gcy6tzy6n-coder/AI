# 规范审查清单

## 通用检查项

### 文档质量
- [ ] 文档结构清晰
- [ ] 语言准确无歧义
- [ ] 示例充分
- [ ] 图表清晰

### 一致性
- [ ] 术语使用一致
- [ ] 与现有文档一致
- [ ] 与代码实现一致

### 完整性
- [ ] 覆盖所有场景
- [ ] 边界条件明确
- [ ] 错误处理说明

## 规范类型检查项

### API Schema
- [ ] 字段定义完整
- [ ] 类型定义准确
- [ ] 必填字段标记
- [ ] 示例值提供
- [ ] 版本信息包含

### 引擎规范
- [ ] 职责定义清晰
- [ ] 接口定义完整
- [ ] 数据模型定义
- [ ] 性能要求明确
- [ ] 错误处理说明

### ADR (架构决策记录)
- [ ] 背景描述清楚
- [ ] 决策明确
- [ ] 理由充分
- [ ] 影响分析完整
- [ ] 替代方案考虑

### 实验协议
- [ ] 目标明确
- [ ] 方法可行
- [ ] 指标可测量
- [ ] 流程清晰

## 审查流程

1. **提交**: 提交规范文档
2. **审查**: 审查者逐项检查
3. **讨论**: 讨论发现的问题
4. **修订**: 作者修订文档
5. **确认**: 审查者确认通过
6. **归档**: 文档归档

## 冻结文档特殊流程

docs/01_theory_frozen/ 中的文档为冻结文档:
- 原则上不接受修改
- 如需修改，需经过特殊审批流程
- 修改需记录在 ADR 中
