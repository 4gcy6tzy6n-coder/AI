# 前向主流程

## 概述

前向主流程是 Post Transformer AI 系统的核心处理流水线，负责协调各个引擎完成用户请求。

## 流程图

```
┌─────────────┐
│  输入接收   │
└──────┬──────┘
       ▼
┌─────────────┐
│  Unit 解析  │
└──────┬──────┘
       ▼
┌─────────────┐     ┌─────────────┐
│ 思考引擎    │◄───►│ 检索引擎    │
└──────┬──────┘     └─────────────┘
       ▼
┌─────────────┐
│ TSLA 评估   │
└──────┬──────┘
       ▼
┌─────────────┐
│ 记忆调度    │
└──────┬──────┘
       ▼
┌─────────────┐
│  输出生成   │
└─────────────┘
```

## 详细步骤

### 1. 输入接收 (Input Reception)

**输入**: 用户查询或外部信号
**输出**: 原始输入对象

**处理**:
- 接收原始输入
- 记录时间戳和会话信息
- 初步格式验证

### 2. Unit 解析 (Unit Parsing)

**输入**: 原始输入对象
**输出**: 结构化 Unit

**处理**:
- 解析用户意图
- 确定 Unit 类型
- 提取关键参数
- 生成 Unit ID

### 3. 思考引擎 (Thinking Engine)

**输入**: 结构化 Unit
**输出**: 推理结果 + 中间步骤

**处理**:
- 分析问题结构
- 生成推理计划
- 执行推理步骤
- 必要时触发检索

### 4. 检索引擎 (Retrieval Engine)

**输入**: 检索查询
**输出**: 相关证据包

**处理**:
- 内部记忆检索
- 外部知识检索
- 证据排序和过滤
- 相关性评分

### 5. TSLA 评估 (TSLA Evaluation)

**输入**: 处理结果
**输出**: 评估决策

**处理**:
- 计算可信度分数
- 风险评估
- 决策路由
- 审计记录

### 6. 记忆调度 (Memory Scheduling)

**输入**: 评估后的结果
**输出**: 存储确认

**处理**:
- 确定存储区域
- 执行门控检查
- 写入记忆存储
- 更新索引

### 7. 输出生成 (Output Generation)

**输入**: 最终结果
**输出**: 用户响应

**处理**:
- 格式化输出
- 附加元数据
- 返回给用户

## 并发处理

### 并行引擎
- 检索引擎可与思考引擎并行运行
- 多个检索查询可并发执行

### 同步点
- 思考引擎需要检索结果时同步
- TSLA 评估作为最终同步点

## 错误处理

### 引擎失败
1. 记录失败信息
2. 尝试降级处理
3. 通知用户或重试

### 超时处理
1. 设置各阶段超时
2. 超时后返回部分结果
3. 记录超时事件
