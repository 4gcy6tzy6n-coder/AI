# 消融实验计划

## 概述

消融实验用于评估各组件对系统整体性能的贡献，识别关键组件和冗余组件。

## 实验目标

1. 量化各组件的贡献
2. 识别关键路径
3. 发现冗余组件
4. 优化系统架构

## 实验设计

### 1. 组件级消融

逐个移除或禁用组件，观察性能变化。

#### 实验组

| 实验组 | 描述 | 操作 |
|--------|------|------|
| Baseline | 完整系统 | 无 |
| -Thinking | 无思考引擎 | 禁用思考引擎 |
| -Retrieval | 无检索引擎 | 禁用检索引擎 |
| -Memory | 无记忆系统 | 禁用记忆系统 |
| -TSLA | 无 TSLA | 禁用 TSLA 评估 |

#### 评估指标
- 任务完成率
- 输出质量分数
- 响应延迟
- 资源消耗

### 2. 功能级消融

在组件内部进行功能消融。

#### 思考引擎消融

| 实验组 | 描述 |
|--------|------|
| -Planner | 禁用规划器 |
| -ConflictResolver | 禁用冲突解决器 |
| -DeepReasoning | 限制推理深度 |

#### 检索引擎消融

| 实验组 | 描述 |
|--------|------|
| -Internal | 仅外部检索 |
| -External | 仅内部检索 |
| -Ranking | 禁用排序 |

#### 记忆系统消融

| 实验组 | 描述 |
|--------|------|
| -Transient | 禁用瞬态记忆 |
| -LongTerm | 禁用长期记忆 |
| -Gates | 禁用门控机制 |

### 3. 参数消融

调整关键参数，观察影响。

#### TSLA 阈值消融

| 实验组 | 接受阈值 | 拒绝阈值 |
|--------|----------|----------|
| Strict | 0.9 | 0.3 |
| Standard | 0.8 | 0.3 |
| Lenient | 0.7 | 0.2 |

#### 记忆层级消融

| 实验组 | Transient | Long-term | Shallow | Deep |
|--------|-----------|-----------|---------|------|
| Full | ✓ | ✓ | ✓ | ✓ |
| Minimal | ✓ | - | - | - |
| Standard | ✓ | ✓ | - | - |

## 实验流程

```
准备阶段
    │
    ├── 准备测试数据集
    ├── 配置实验环境
    └── 建立基线
    │
    ▼
执行阶段
    │
    ├── 运行组件级消融
    ├── 运行功能级消融
    └── 运行参数消融
    │
    ▼
分析阶段
    │
    ├── 统计分析
    ├── 可视化结果
    └── 撰写报告
```

## 数据集

### 主要数据集
- 100 个标准测试案例
- 覆盖各功能场景

### 评估指标

#### 主要指标
- 准确率 (Accuracy)
- 召回率 (Recall)
- F1 分数

#### 辅助指标
- 延迟变化百分比
- 资源消耗变化百分比
- 用户体验评分

## 结果分析

### 贡献度计算

```
组件贡献度 = (Baseline性能 - 消融后性能) / Baseline性能
```

### 敏感性分析

- 高敏感组件: 贡献度 > 30%
- 中敏感组件: 贡献度 10-30%
- 低敏感组件: 贡献度 < 10%
